## 1. Mục tiêu & Ranh giới trách nhiệm

Subagent A14 chịu trách nhiệm toàn diện về âm thanh tổng hợp (Text-to-Speech), thu âm micro (Web Audio API) và mô phỏng trực quan cao độ (Pitch Contour):

1. **Tổng hợp giọng đọc tiếng Hoa chuẩn Đài Loan (`zh-TW` Preference):**
   - Phân tích và ưu tiên hàng đầu các giọng tiếng Hoa Phồn thể Đài Loan tự nhiên (`zh-TW`, `cmn-Hant-TW`, `zh-Hant-TW`, Microsoft HsiaoChen/YunJhe/HsiaoYu, Google 國語 臺灣, Apple Mei-Jia/Sin-Ji/Ting-Ting).
   - Thiết lập cơ chế dự phòng có thứ bậc chặt chẽ: nếu thiết bị thiếu giọng Đài Loan, tự động chuyển tiếp sang Hồng Kông (`zh-HK`), sau đó sang giọng Phổ thông (`zh-CN`), và cuối cùng là giọng tiếng Hoa tổng quát (`zh`).
   - Phạt điểm các giọng tổng hợp desktop cũ kỹ, máy móc (Windows SAPI5 Desktop `Hanhan`, `Desktop`).
2. **Khắc phục lỗi Chromium V8 Garbage Collection trên `SpeechSynthesisUtterance`:**
   - Trong trình duyệt nhân Chromium (Chrome, Edge, Brave), bộ thu gom rác V8 có thể giải phóng đối tượng `SpeechSynthesisUtterance` ngay giữa lúc đang phát nếu đối tượng không được neo giữ vào phạm vi toàn cục (`window`), dẫn đến việc âm thanh bị ngắt đột ngột hoặc sự kiện `onend` không bao giờ được kích hoạt.
   - Neo giữ đối tượng đang phát vào cả biến module và thuộc tính `window.__zhongxue_active_utterance` / `window.__zhongxue_utterance_retains` (Set), tự động giải phóng khi phát xong (`onend`) hoặc khi xảy ra lỗi (`onerror`).
3. **Cơ chế dừng và hủy phát âm sạch sẽ (`stopSpeaking`, `cancelSpeech`):**
   - Hủy âm thanh ngay lập tức khi người dùng click dừng, khi chuyển từ hoặc khi component unmount, không để âm thanh phát kéo dài sang màn hình khác.
   - Bỏ qua các sự kiện lỗi `interrupted` và `canceled` do trình duyệt phát sinh khi chủ động hủy, không làm xuất hiện thông báo lỗi giả trên giao diện.
4. **Xử lý duyên dáng khi trình duyệt không hỗ trợ Web Speech API:**
   - Kiểm tra an toàn trước khi gọi: nếu trình duyệt thiếu `speechSynthesis` hoặc `SpeechSynthesisUtterance`, trả về `false` và kích hoạt callback `onError` thân thiện để người học chuyển sang luyện qua Pinyin.
5. **Thu âm Micro & Phát hiện Cao độ F0 (`detectPitchF0` / Web Audio API):**
   - Kiểm tra ngữ cảnh bảo mật (`window.isSecureContext === true`): trên môi trường không phải HTTPS hoặc localhost, trình duyệt khóa quyền micro; hiển thị thông báo rõ ràng và chuyển sang chế độ mô phỏng trực quan.
   - Xử lý các ngoại lệ truy cập micro: người dùng từ chối cấp quyền (`NotAllowedError`), không có thiết bị micro (`NotFoundError`), hoặc thao tác bị hủy giữa chừng (`AbortError`).
   - Đảm bảo giải phóng 100% tài nguyên phần cứng: dừng toàn bộ các track `MediaStreamTrack.stop()` (tắt biểu tượng chấm cam micro trên macOS/iOS) và đóng `AudioContext.close()` trong khối `finally`.
6. **Minh bạch UX — Phân biệt phép đo thật vs mô phỏng hướng dẫn:**
   - Tuyệt đối không giả mạo điểm số (như tự gán "96.2% Trùng khớp") khi chưa có luồng âm thanh thực từ micro.
   - Khi chưa thu âm hoặc khi micro bị từ chối/không khả dụng: hiển thị nhãn rõ ràng **"Mô phỏng hướng dẫn"**, đường vẽ ghi rõ **"Đường mô phỏng mẫu"**.
   - Khi đã thu âm và đo đạc thành công: hiển thị nhãn **"Đo thực tế: {F0} Hz"**, đường vẽ ghi rõ **"Giọng bạn ({F0} Hz)"**, kèm tần số F0 đo được và đối chiếu với thang điểm thanh điệu Chao.

### 2.2 Neo giữ tham chiếu Utterance chống Chromium V8 Garbage Collection

Khai báo mở rộng kiểu toàn cục và quản lý danh sách giữ chỗ:

```typescript
declare global {
    interface Window {
        __zhongxue_active_utterance?: SpeechSynthesisUtterance | null;
        __zhongxue_utterance_retains?: Set<SpeechSynthesisUtterance>;
    }
}

function retainUtterance(utt: SpeechSynthesisUtterance): void {
    activeUtterance = utt;
    if (typeof window !== 'undefined') {
        window.__zhongxue_active_utterance = utt;
        if (!window.__zhongxue_utterance_retains) {
            window.__zhongxue_utterance_retains = new Set();
        }
        window.__zhongxue_utterance_retains.add(utt);
    }
}

function releaseUtterance(utt: SpeechSynthesisUtterance | null): void {
    if (activeUtterance === utt) activeUtterance = null;
    if (typeof window !== 'undefined') {
        if (window.__zhongxue_active_utterance === utt) {
            window.__zhongxue_active_utterance = null;
        }
        if (utt && window.__zhongxue_utterance_retains) {
            window.__zhongxue_utterance_retains.delete(utt);
        }
    }
}
```

Khi người dùng gọi `stopSpeaking()` hoặc `cancelSpeech()`, hàm sẽ hủy `window.speechSynthesis.cancel()`, dọn dẹp `Set` và đặt `window.__zhongxue_active_utterance = null`.

### 2.3 Thuật toán phát hiện cao độ F0 Autocorrelation (`detectPitchF0`)

Thuật toán tự tương quan miền thời gian (Time-Domain Autocorrelation):
1. **Lọc cổng tiếng ồn (Noise Gate):** Tính căn bậc hai trung bình bình phương (RMS). Nếu `rms < 0.015`, xem là im lặng hoặc nhiễu nền, trả về `-1`.
2. **Khoảng dịch chuyển mục tiêu (Human Voice F0 Range):** Giới hạn tần số cơ bản giọng người từ $80\text{ Hz}$ (nam trầm) đến $450\text{ Hz}$ (nữ cao/trẻ em):
   $$\text{minOffset} = \lfloor \text{sampleRate} / 450 \rfloor, \quad \text{maxOffset} = \lfloor \text{sampleRate} / 80 \rfloor$$
3. **Tìm độ trễ cực đại:**
   $$\text{corr}(\tau) = \sum_{i=0}^{N-\tau} x[i] \cdot x[i+\tau]$$
4. **Tính tần số cơ bản:**
   $$F_0 = \frac{\text{sampleRate}}{\tau_{\max}}$$

1. **Kiểm thử trên thiết bị phần cứng thật:**
   - Trong môi trường Node.js / CI, toàn bộ Web Speech API và Web Audio API được kiểm thử thông qua mock đầy đủ các nhánh logic.
   - Khi chạy ứng dụng trên thiết bị thực (Windows/macOS/iOS/Android), chất lượng giọng đọc phụ thuộc vào engine TTS cài đặt trên hệ điều hành (ví dụ: Windows cần gói ngôn ngữ Chinese Traditional Taiwan để có giọng HsiaoChen/YunJhe chất lượng cao; iOS có sẵn giọng Mei-Jia).
2. **Ảnh hưởng của môi trường ồn:**
   - Thuật toán `detectPitchF0` có ngưỡng lọc ồn RMS $0.015$. Trong môi trường quá ồn hoặc micro có gain quá thấp, ứng dụng sẽ thông báo không phát hiện giọng nói rõ ràng và chuyển sang đường mô phỏng mẫu để người học không bị gián đoạn trải nghiệm học tập.
