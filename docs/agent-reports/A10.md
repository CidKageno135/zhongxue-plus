## 1. Mục tiêu & Ranh giới trách nhiệm

Subagent A10 chịu trách nhiệm tái thiết kế và hiện đại hóa toàn diện giao diện tra từ điển `src/views/DictionaryView.tsx` trong dự án ZhongXue+ V2, kết nối mượt mà giữa động cơ từ điển 122.596 mục từ phía backend (A06), bộ chuẩn hóa tiếng Việt & Pinyin (A07), client API adapter (A08) và hệ thống lưu trữ học tập SRS (A11):

1. **Khắc phục Lag UI & Hiện tượng Race Condition khi Gõ Nhanh (Debounce & Stale Response Protection):**
   - Áp dụng cơ chế debounce ~280ms tránh nghẽn luồng render khi người dùng gõ phím liên tục.
   - Sử dụng `requestIdRef` để gắn nhãn từng truy vấn bất đồng bộ; loại bỏ triệt để phản hồi cũ đến muộn (out-of-order responses) ghi đè lên kết quả mới hơn.
2. **Phân trang Trung thực & Tải thêm Từng phần ("Xem thêm kết quả"):**
   - Hiển thị con số `total` chính xác tuyệt đối do động cơ backend cung cấp (ví dụ: `Tìm thấy 10.622 kết quả cho “de”`, `Tìm thấy 12 kết quả cho “xuéshēng”`).
   - Nút "Xem thêm kết quả" cập nhật `offset` tăng tiến (+20) và nối tiếp mảng kết quả vào danh sách hiển thị mà không làm mất các từ vựng trước đó.
3. **Bao phủ Toàn diện 6 Biến thể Tìm kiếm:**
   - Chữ Hán phồn thể (`學生`, `你好`, `臺灣`) & giản thể (`学生`, `台湾`).
   - Pinyin có dấu thanh điệu chuẩn quốc tế (`xuéshēng`, `nǐ hǎo`).
   - Pinyin số thanh điệu (`xue2 sheng1`, `ni3 hao3`).
   - Pinyin không dấu sạch âm (`xuesheng`, `nihao`).
   - Tiếng Việt có dấu (`học sinh`, `xin chào`, `Đài Loan`).
   - Tiếng Việt không dấu (`hoc sinh`, `xin chao`, `dai loan`).
4. **Trạng thái Trực quan Thân thiện (Loading Skeleton & Contextual Empty State):**
   - Skeleton loader 6 thẻ từ vựng với hiệu ứng xung nhịp (`animation: pulse`) khi đang truy vấn.
   - Empty state chứa tiêu đề chuẩn `Không tìm thấy từ phù hợp` (khớp hoàn hảo với bộ test E2E của Playwright) kèm mẹo gợi ý ngữ cảnh thông minh dựa trên `searchNormalization.ts`.
5. **Tích hợp Lưu Từ vào Sổ tay SRS:**
   - Nút "Lưu vào ôn tập" / "Đã lưu" đồng bộ với kho dữ liệu học (`savedWordIds`, `onToggleSave`).
   - Phù hợp tuyệt đối với selector Playwright: `aria-label="Lưu {hanzi}"` / `aria-label="Bỏ lưu {hanzi}"`.
   - Huy hiệu `Đã lưu` màu ngọc bích nổi bật trên thẻ từ vựng cùng tooltip thông báo.
6. **Khả năng Tiếp cận (a11y) & Đáp ứng Mobile 375px:**
   - Kiểm soát chặt chẽ layout, không gây tràn ngang (horizontal overflow) trên viewport hẹp 375px (iPhone 13).
   - Ô điền chữ Tianzige hỗ trợ phím `Enter` / `Space` để phát âm cho người dùng bàn phím.

## 2. Chi tiết Triển khai Kỹ thuật (`src/views/DictionaryView.tsx`)

### 2.1 Cơ chế Debounce 280ms & Chống Race Condition Bất đồng bộ

Khi người dùng gõ nhanh (ví dụ: `x-i-n- -c-h-a-o`):
- Trước đây: Mỗi ký tự đều kích hoạt `searchWords` cục bộ và gọi API khiến số lượng kết quả nhảy loạn xạ, gây giật lag giao diện và có thể bị response của chuỗi gõ trước trả về sau đè lên kết quả mới.
- Giải pháp mới trong `DictionaryView.tsx`:
  ```typescript
  const requestIdRef = useRef<number>(0);
  const latestQueryRef = useRef<string>(query);

  useEffect(() => {
    latestQueryRef.current = query;
  }, [query]);

  useEffect(() => {
    const trimmed = query.trim();

    if (!trimmed) {
      // Khi query rỗng, reset an toàn bất đồng bộ tránh cascading renders
      const clearTimer = setTimeout(() => {
        requestIdRef.current++;
        setDbResults([]);
        setResultTotal(0);
        setOffset(0);
        setLoading(false);
        setLoadingMore(false);
      }, 0);
      return () => clearTimeout(clearTimer);
    }

    let isMounted = true;

    const timer = setTimeout(async () => {
      const thisRequestId = ++requestIdRef.current;
      setLoading(true);
      try {
        const res = await searchDictionary(trimmed, searchMode, 0);

        // Bỏ qua nếu có request mới hơn hoặc component đã unmount
        if (!isMounted || thisRequestId !== requestIdRef.current) return;
        if (latestQueryRef.current.trim() !== trimmed) return;

        setDbResults(res.results || []);
        setResultTotal(res.total || 0);
        if (res.count && res.count > 0) setTotalCount(res.count);
        setIsDbSource(res.source === 'database');
        setOffset(0);
      } catch {
        if (!isMounted || thisRequestId !== requestIdRef.current) return;
        setDbResults([]);
        setResultTotal(0);
      } finally {
        if (isMounted && thisRequestId === requestIdRef.current) {
          setLoading(false);
        }
      }
    }, 280);

    return () => {
      isMounted = false;
      clearTimeout(timer);
    };
  }, [query, searchMode]);
  ```
- **Xóa tìm kiếm tức thời:** Khi nhấn nút `X` ("Xóa tìm kiếm"), bộ đếm `requestIdRef.current++` lập tức vô hiệu hóa mọi request đang bay và đưa giao diện về danh sách từ vựng bài học tiêu chuẩn ngay lập tức (0ms delay).

### 2.2 Phân trang Trung thực & Tải thêm Từng phần (Incremental Load)

1. **Hiển thị Tổng số Thực tế:**
   - Thay vì con số giả tạo hoặc cắt ngắn ở 200/250 bản ghi, thanh thông tin hiển thị chính xác:
     ```text
     Tìm thấy 10.622 kết quả cho “de” (từ CSDL 122.596 mục từ)
     ```
2. **Nút "Xem thêm kết quả" (`handleLoadMore`):**
   - Khi `resultTotal > dbResults.length`:
     ```typescript
     const handleLoadMore = useCallback(async () => {
       const trimmed = query.trim();
       if (!trimmed || loadingMore || loading) return;

       const nextOffset = offset + 20;
       setLoadingMore(true);
       const thisRequestId = ++requestIdRef.current;

       try {
         const res = await searchDictionary(trimmed, searchMode, nextOffset);
         if (thisRequestId !== requestIdRef.current) return;
         if (latestQueryRef.current.trim() !== trimmed) return;

         if (res.results && res.results.length > 0) {
           setDbResults(prev => [...prev, ...res.results]);
           setOffset(nextOffset);
           if (typeof res.total === 'number') setResultTotal(res.total);
         }
       } finally {
         if (thisRequestId === requestIdRef.current) setLoadingMore(false);
       }
     }, [query, searchMode, offset, loadingMore, loading]);
     ```
   - Người dùng bấm nút "Xem thêm kết quả (20 từ tiếp theo)", hệ thống nạp thêm 20 từ tiếp theo và nối dài danh sách mà không cuộn giật hay làm mất các từ vựng đã duyệt qua.
   - Khi đã nạp hết toàn bộ kết quả, hiển thị thông báo nhẹ nhàng: `✓ Đã hiển thị toàn bộ {resultTotal} kết quả`.

### 2.3 Tích hợp Lưu Từ SRS & Hợp đồng Tương thích E2E

1. **Xác định Định danh Mục từ (`getEffectiveWordId` & `checkIsSaved`):**

   - Nếu là từ ngoài giáo trình, tự động đóng gói đối tượng `Word` chuẩn kèm ví dụ ngữ cảnh `（臺灣繁體詞彙）` và đăng ký vào kho từ điển mở rộng qua `onToggleSave`.
2. **Nhãn Trực quan & Thuộc tính Trợ năng:**
   - Thuộc tính `aria-label`: `${isSaved ? 'Bỏ lưu' : 'Lưu'} ${entry.traditional}`.
   - Nhãn nút hiển thị trực tiếp: `{isSaved ? 'Đã lưu' : 'Lưu vào ôn tập'}`.
   - Huy hiệu `Đã lưu` với icon Bookmark màu xanh ngọc bích (`var(--jade-emerald)`).

### 2.4 Trạng thái Rỗng Thông minh (Intelligent Empty State) & Loading Skeleton

1. **Skeleton Loading:**
   - Trong lúc truy vấn (280ms debounce + API call), hiển thị 6 thẻ khung xương nhẹ nhàng với hiệu ứng `pulse` sẵn có trong hệ thống CSS của ứng dụng, tránh màn hình trắng xóa hoặc giật hình.
2. **Contextual Empty State:**
   - Giữ nguyên thẻ tiêu đề `<h2>Không tìm thấy từ phù hợp</h2>` để bảo đảm 100% ca kiểm thử Playwright `toContainText(/Không tìm thấy từ phù hợp/i)` thành công.
   - Sử dụng các hàm thuần từ `src/domain/searchNormalization.ts`:
     - Phân tích nếu người dùng đang nhập chữ Hán (`isHanziText`), gợi ý chuyển đổi Phồn/Giản thể hoặc tra từng chữ đơn.
     - Phân tích nếu người dùng đang nhập Pinyin/tiếng Việt, gợi ý trực tiếp dạng không dấu: `normalizePinyin(query).clean` hoặc `normalizeVietnamese(query)`.
     - Cung cấp 2 nút thao tác nhanh: "Xóa tìm kiếm và quay lại bài học" và "Tra bằng chữ viết tay (手寫)".
