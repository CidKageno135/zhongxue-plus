## 1. Phạm vi công việc đã thực hiện

### 1.1. Giai đoạn Wave 0: Thiết lập Hợp đồng & Hạ tầng Kiểm thử
1. **Khóa Hợp đồng API Toàn diện (`docs/API-CONTRACT.md`):**
   - Định nghĩa chi tiết DTO và mã lỗi HTTP chuẩn cho 4 endpoint: `/api/health`, `/api/dictionary`, `/api/conversation`, `/api/handwriting`.
   - Chuẩn hóa mã lỗi và DTO bao bọc lỗi `ApiErrorBody` (`BAD_REQUEST`, `UNAUTHORIZED_BASE_URL`, `NOT_FOUND`, `UPSTREAM_TIMEOUT`, `SERVICE_UNAVAILABLE`,...).
   - Quy định rõ ràng hợp đồng 4 trạng thái AI: `ai` (live model response), `guided` (local smart fallback kèm nhãn rõ ràng), `offline` (ngoại tuyến), `error` (lỗi không thể khôi phục).
   - Thiết lập quy tắc thời gian chờ (timeout) chặt chẽ: deadline máy chủ mặc định **12 giây** (`12000ms`), trần tối đa 15 giây; hủy yêu cầu ngay lập tức qua `AbortController` khi client ngắt kết nối.
   - Thiết lập ranh giới bảo mật máy chủ (A03 Security Constraints): Khóa API trong `.env` máy chủ chỉ được gửi tới provider tin cậy (`agentrouter.org`, `openrouter.ai`); nếu client gửi `baseUrl` tùy biến mà không gửi kèm `apiKey` riêng thì máy chủ từ chối yêu cầu, tuyệt đối không gửi khóa của server.
   - Chuẩn hóa phân rã module backend và quyền sở hữu tệp (A02 đến A08) để đạt kiến trúc Không-Phân-Kỳ (Zero-Divergence) giữa môi trường dev và production.

2. **Cập nhật Cấu hình Vitest & Phạm vi Khám phá Test (`vite.config.ts`):**
   - Mở rộng `test.include` từ `['tests/domain*.test.ts']` thành `['tests/**/*.test.ts']` để tự động nhận diện tất cả các bài test đơn vị, bảo mật và tích hợp mới do A03, A04, A05, A06, A07, A16 viết.
   - Cấu hình `coverage.include` bao phủ: `['src/domain/**', 'src/services/**', 'server/**']`.

3. **Cập nhật `package.json` & Chuẩn bị Runners:**
   - Bổ sung đầy đủ các script bắt buộc:
     - `"start": "vite-node server/index.ts"` (chạy production server độc lập)
     - `"test:security": "vitest run --configLoader runner --passWithNoTests tests/security-policy.test.ts tests/integration/api-security.test.ts"`
     - `"test:integration": "vitest run --configLoader runner --passWithNoTests tests/integration/**/*.test.ts"`
     - `"test:e2e:prod": "playwright test --config=playwright.prod.config.ts"`
   - Duy trì nguyên vẹn các script nền tảng: `dev`, `build`, `lint`, `typecheck`, `test`, `test:coverage`, `test:e2e`.
   - Kiểm tra và xác nhận trình chạy TypeScript cho backend: đã có sẵn `vite-node` (v3.2.4) trong `devDependencies` và Node 24 hỗ trợ cờ native `--experimental-strip-types`.

4. **Cấu hình TypeScript (`tsconfig.json` & `tsconfig.server.json`):**
   - Cập nhật `tsconfig.json` thêm `"server"` vào `"include": ["src", "server"]` và bổ sung `"node"` vào `"types": ["vite/client", "node"]` để lệnh `tsc -b --pretty false` tự động kiểm tra cú pháp và kiểu dữ liệu của mã backend trong thư mục `server/` mà không làm hỏng quá trình biên dịch client.
   - Tạo thêm `tsconfig.server.json` chuyên biệt cho các subagent backend A02–A06 khi cần typecheck độc lập.

5. **Cấu hình Playwright cho Production Server (`playwright.config.ts` & `playwright.prod.config.ts`):**
   - Tạo `playwright.prod.config.ts` chuyên biệt để chạy E2E trực tiếp trên máy chủ production sau khi build (`npm run build && npm run start`), kiểm tra đúng URL `http://127.0.0.1:3000/api/health`, với `reuseExistingServer: false`.
   - Cập nhật `playwright.config.ts` hỗ trợ biến môi trường `E2E_PROD=true`.

6. **Bổ sung Canonical DTO Types vào `src/types.ts`:**
   - Bổ sung các kiểu dữ liệu dùng chung: `DbDictionaryResult`, `DictionarySearchResponse`, `HealthResponse`, `ConversationTurn`, `ConversationAction`, `ConversationRequestBody`, `ConversationReplyMode`, `ConversationReply`, `AiConnectionStatus`, `HandwritingStroke`, `HandwritingRequestBody`, `HandwritingResponse`, `ApiErrorBody`.
   - Giữ nguyên vẹn 100% các interface bài học, ngữ pháp và kịch bản hiện hữu.

### 1.2. Giai đoạn Wave 3: Tích hợp Cuối cùng & Hoàn thiện Kiến trúc Zero-Divergence
1. **Rút gọn toàn diện `src/viteApiPlugin.ts` thành Dev Adapter mỏng (~75 dòng):**
   - Loại bỏ hoàn toàn hơn 700 dòng code cũ trùng lặp chứa logic phân tích từ điển thô, AI caller không an toàn và lỗi rò rỉ khóa môi trường (`SEC-01`).
   - Nạp trực tiếp `handleApiRequest` từ `server/app.ts`.
   - Khởi tạo `dictionaryEngine.init(dictPath)` từ `server/dictionary.ts` khi Vite server và preview server khởi động.
   - Đăng ký middleware Vite qua `server.middlewares.use`:
     ```typescript
     const handled = await handleApiRequest(req, res);
     if (!handled) next();
     ```
   - Nhờ đó, cả máy chủ phát triển Vite (`npm run dev`) và máy chủ độc lập Production (`npm run start`) đều dùng **100% chung một logic định tuyến, xác thực, bảo mật, và xử lý dữ liệu**. Không còn bất kỳ sự phân kỳ nào giữa dev và prod!
