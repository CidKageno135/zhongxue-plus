## 1. Tổng quan Mục tiêu & Phạm vi Công việc

Subagent A18 chịu trách nhiệm thiết kế, mở rộng và chuẩn hóa toàn bộ các kịch bản kiểm thử E2E Playwright liên quan đến tiến trình học tập bài học chuẩn giáo trình, màn hình cấu hình hệ thống & ranh giới bảo mật AI phía máy khách, chuẩn tiếp cận WAI-ARIA / bàn phím cho các thành phần tương tác cao (HandwritingPad, ReviewView flashcards), và bảo đảm tính toàn vẹn layout không tràn ngang trên màn hình di động chuẩn 375×667 (iPhone SE / iPhone 13).

### Các kết quả then chốt đã hoàn thành:
1. **Kiểm thử Giáo trình & Bài học (`lesson.spec.ts`):**
   - Kiểm tra toàn diện toàn bộ 16 bài học chuẩn TOCFL A1–B2 trong cơ sở dữ liệu `src/data/lessons.ts`.
   - Xác thực cả 4 bước của mỗi bài học:
     - **Bước 1 (Từ vựng):** Khung Điền Tự Cách, danh sách từ vựng chuẩn, nút phát âm `SpeakButton`.
     - **Bước 2 (Hội thoại):** Các lượt thoại song ngữ Phồn thể - Pinyin - Tiếng Việt kèm phát âm.
     - **Bước 3 (Ngữ pháp):** Tiêu đề, mẫu câu cú pháp và ví dụ thực chiến.
     - **Bước 4 (Thử sức - Quiz):** Bộ câu hỏi trắc nghiệm A/B/C/D, kiểm tra phản hồi đúng/sai và giải thích chi tiết.
   - Kiểm tra tích lũy điểm thưởng XP (+30 XP) khi hoàn tất bài học, hiển thị cập nhật tức thì trên huy hiệu đá quý Topbar (`.bento-gem-pill`) và lưu trữ bền vững qua tải lại trang.
   - Xác thực nút phát âm (`aria-label="Nghe phát âm"`) trên từ vựng và câu thoại hoạt động trơn tru, không gây lỗi runtime.
   - Kiểm định layout đáp ứng (responsive) trên màn hình di động 375×667 qua từng bước học, không phát sinh tràn ngang (`scrollWidth <= clientWidth`).

2. **Kiểm thử Cài đặt, Bảo mật AI & Hội thoại (`settings-conversation.spec.ts`):**
   - **Chế độ Server-Key (Mặc định - An toàn):** Hiển thị rõ ràng chuỗi `"Sử dụng khóa máy chủ (Mặc định - An toàn)"`, xác nhận không lưu trữ bất kỳ API key nào trong `localStorage` (`zhongxue.ai.config`), và kiểm tra intercept request không gửi trường `apiKey` lên backend.
   - **Thử nghiệm kết nối AI (Ping Probe):** Mock endpoint `POST /api/conversation` với `{ action: 'ping' }`, hiển thị chính xác độ trễ roundtrip (`95ms`), nhà cung cấp và huy hiệu xanh xác nhận kết nối thành công.
   - **Chế độ Client-Key (Khóa cá nhân):** Người dùng nhập API key riêng -> lưu an toàn vào `localStorage`. Khi nhấn nút "Xóa khóa" -> dọn sạch key khỏi bộ nhớ trình duyệt và hoàn nguyên về chế độ Server-Key.
   - **Cảnh báo an ninh chính sách A03 cho BaseUrl lạ:** Khi nhập endpoint tùy biến ngoài allowlist (ví dụ `https://attacker.evil.com/v1`), giao diện lập tức kích hoạt cảnh báo an ninh nổi bật: máy chủ sẽ KHÔNG chuyển tiếp khóa hệ thống.
   - **Quản lý Hồ sơ & Dữ liệu:** Đổi tên hồ sơ, lưu mục tiêu học ngày (`10, 20, 30, 50, 100`), xuất tệp `zhongxue-tien-do.json`, chặn nhập tệp hỏng, yêu cầu gõ đúng chuỗi `XÓA` khi reset, và phục hồi nguyên vẹn tiến độ sau khi import tệp hợp lệ.
   - **Kịch bản hội thoại phân nhánh:** Giải thích phản hồi chưa phù hợp, hỗ trợ làm rõ và hoàn thành tình huống.

3. **Kiểm thử Chuẩn tiếp cận & Hồi quy Giao diện (`accessibility-regression.spec.ts`):**
   - **WAI-ARIA Modal Dialog (HandwritingPad):**
     - Đầy đủ thuộc tính chuẩn: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, `aria-describedby`.
     - **Bẫy tiêu điểm (Focus Trap):** Tự động di chuyển tiêu điểm vào nút đóng khi mở; phím `Tab` và `Shift+Tab` bị khóa trong phạm vi modal, không rò rỉ ra background.
     - **Đóng sạch sẽ:** Hỗ trợ phím `Escape` và click vào vùng phủ nền (backdrop click); tự động hoàn trả tiêu điểm chính xác về nút gọi `Viết tay (手寫)` ban đầu.
   - **Bảo vệ Phím tắt Ôn tập SRS (ReviewView):**
     - Phím `Space` lật thẻ; các phím số `1`, `2`, `3`, `4` **CHỈ** được phép đánh giá khi thẻ đã lật. Khi thẻ chưa lật, nhấn 1–4 không gây bất kỳ tác động nào.
     - **Hàng rào Chống Nhập liệu (Typing Guard):** Khi người dùng đang focus trong `<input>`, `<textarea>`, `<select>` hoặc phần tử soạn thảo, toàn bộ phím tắt `Space` và `1–4` bị chặn tuyệt đối.
     - **Hàng rào Hộp thoại Modal (Modal Dialog Guard):** Khi phát hiện bất kỳ modal dialog nào đang mở trên DOM, toàn bộ phím tắt ôn tập bị khóa hoàn toàn.
   - **Kiểm định Toàn diện Viewport Di động 375px (Mobile Layout Audit):**
     - Kiểm tra không tràn ngang (`document.documentElement.scrollWidth <= window.innerWidth` và `document.body.scrollWidth <= window.innerWidth`) trên tất cả các view:
       1. Trang chủ Hôm nay (`Today`)
       2. Lộ trình Giáo trình (`PathView`)
       3. Chi tiết Tiến trình Bài học (`LessonFlow`)
       4. Tra cứu Từ điển (`DictionaryView`)
       5. Ôn tập Thẻ SRS (`ReviewView`)
       6. Luyện giao tiếp AI & Tình huống (`ConversationListView`)
       7. Cài đặt Hồ sơ & AI Provider (`SettingsView`)

### 2.2 Cài đặt & Ranh giới Bảo mật AI (`tests/e2e/settings-conversation.spec.ts`)
```typescript
test('server-key mode is selected by default with privacy isolation, no key in localStorage or request', async ({ page }) => {
  let interceptedApiKey: string | undefined = 'INITIAL_SENTINEL';
  await page.route('**/api/conversation', async route => {
    const req = route.request();
    if (req.method() === 'POST') {
      const body = req.postDataJSON();
      if (body?.action === 'ping') {
        interceptedApiKey = body.apiKey;
        await route.fulfill({
          status: 200,
          contentType: 'application/json',
          body: JSON.stringify({
            ok: true,
            provider: 'AgentRouter (gpt-6.1-sol)',
            model: 'gpt-6.1-sol',
            baseUrl: 'https://agentrouter.org/v1',
            latencyMs: 95
          })
        });
        return;
      }
    }
    await route.continue();
  });

  await expect(page.getByText('Sử dụng khóa máy chủ (Mặc định - An toàn)')).toBeVisible();
  const serverRadio = page.locator('input[type="radio"][value="server"]');
  await expect(serverRadio).toBeChecked();

  // Bấm ping và xác thực hiển thị kết quả latency 95ms
  await page.getByRole('button', { name: /Kiểm tra kết nối AI \(Ping\)/ }).click();
  await expect(page.getByText(/Kết nối AI thành công!/)).toBeVisible();
  await expect(page.getByText(/95ms/)).toBeVisible();

  // Xác thực tuyệt đối không có key máy khách gửi lên
  expect(interceptedApiKey).toBeUndefined();
});
```

### 2.3 Khả năng Tiếp cận WAI-ARIA & Viewport Di động 375px (`tests/e2e/accessibility-regression.spec.ts`)
```typescript
test('dialog has role="dialog", aria-modal="true", traps focus, and closes via Escape with focus restored', async ({ page }) => {
  await navigate(page, 'Từ điển');
  const triggerBtn = page.getByRole('button', { name: 'Viết tay (手寫)', exact: true });
  await triggerBtn.click();

  const dialog = page.getByRole('dialog', { name: 'Tra bằng chữ viết tay' });
  await expect(dialog).toHaveAttribute('aria-modal', 'true');

  const closeBtn = page.getByRole('button', { name: 'Đóng bảng viết tay' });
  await expect(closeBtn).toBeFocused({ timeout: 3000 });

  // Escape key closes dialog and restores focus
  await page.keyboard.press('Escape');
  await expect(dialog).not.toBeVisible();
  await expect(triggerBtn).toBeFocused();
});
```
