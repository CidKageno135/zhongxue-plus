## 1. Tổng quan Mục tiêu & Phạm vi Công việc

Subagent A15 chịu trách nhiệm hiện đại hóa toàn diện giao diện Cài đặt (`SettingsView.tsx`), bảo đảm tính toàn vẹn của dữ liệu học tập, tuân thủ nghiêm ngặt chính sách bảo mật máy chủ A03, kiểm định thực tế sức khỏe hệ thống qua `/api/health`, và kiểm tra độ trễ kết nối AI trực tuyến qua endpoint `/api/conversation`.

### Các yêu cầu then chốt đã hoàn thành:
1. **Phân tách Chế độ Khóa Máy chủ (Server-Key) vs Khóa Cá nhân (Client-Key):**
   - **Chế độ 1 — "Sử dụng khóa máy chủ (Mặc định - An toàn)":** Trình duyệt không lưu trữ bất kỳ khóa API nào trong `localStorage` và không truyền trường `apiKey` trong payload gửi lên máy chủ. Máy chủ backend tự động gắn khóa môi trường hệ thống (`AI_SOL_KEY`, `AI_DEEPSEEK_KEY`, `AI_API_KEY`) khi kết nối tới các nhà cung cấp tin cậy.
   - **Chế độ 2 — "Sử dụng khóa cá nhân (Tùy chọn)":** Người học có thể nhập API Key riêng của mình. Có nút "Xóa khóa" để dọn sạch khóa khỏi `localStorage` và lập tức hoàn nguyên về chế độ Khóa máy chủ.
   - **Bảo mật tuyệt đối:** Tuyệt đối không bao giờ hiển thị, nạp hoặc xuất khóa môi trường hệ thống ra phía máy khách, console logs, hoặc tệp JSON sao lưu.
2. **Đồng bộ Điểm cuối & Nhà cung cấp AI (Provider & Endpoint Alignment):**
   - Tích hợp các bộ cấu hình mẫu chuẩn:
     - **AgentRouter (Khuyên dùng):** `https://agentrouter.org/v1` với các mô hình `gpt-6.1-sol` (Gia sư chuyên sâu TOCFL) và `deepseek-v4-flash` (Phản xạ tức thì).
     - **OpenRouter:** `https://openrouter.ai/api/v1` với các mô hình `deepseek/deepseek-chat` và `google/gemini-2.0-flash-001`.
   - **Cảnh báo an ninh chính sách A03 cho Endpoint tùy biến:** Khi người dùng nhập `baseUrl` không thuộc danh sách máy chủ tin cậy (`TRUSTED_AI_HOSTS`), hệ thống lập tức hiển thị bảng cảnh báo nổi bật: Máy chủ sẽ **không bao giờ** chuyển tiếp khóa môi trường tới địa chỉ lạ; người dùng bắt buộc phải dùng chế độ Khóa cá nhân.
3. **Kiểm định Sức khỏe Hệ thống Thực tế (Real Health Probe via `/api/health`):**
   - Thực hiện `GET /api/health` với header `Accept: application/json`.
   - Kiểm tra mã trạng thái HTTP (`200 OK` hoặc `503 Service Unavailable`).
   - Xác thực header `Content-Type: application/json` nhằm ngăn chặn triệt để lỗi SPA fallback (trả về trang HTML 200 khi API gặp sự cố).
   - Hiển thị trực quan trạng thái động cơ từ điển 122.000 từ (`totalEntries`, `loaded`, `loadTimeMs`) và trạng thái cấu hình AI máy chủ.
4. **Kiểm tra Kết nối AI Thực tế (AI Ping Probe via `/api/conversation`):**
   - Nút "⚡ Kiểm tra kết nối AI (Ping)" gửi request `{ action: 'ping', model, baseUrl, apiKey }`.
   - Hiển thị thời gian phản hồi thực tế dạng roundtrip latency tính bằng mili-giây (ms), thông tin nhà cung cấp, hoặc mã lỗi chi tiết nếu kết nối thất bại.
5. **Bảo toàn Hồ sơ Học tập & Quản lý Dữ liệu:**
   - Bảo toàn trường tên học viên (`#profile-name`, tối đa 40 ký tự) và mục tiêu điểm số hàng ngày (10, 20, 30, 50, 100 XP).
   - Xuất dữ liệu học tập ra tệp `zhongxue-tien-do.json` (không chứa API key).
   - Nhập dữ liệu học tập với cơ chế xác thực schema nghiêm ngặt từ `domain/learning.ts`.
   - Xóa toàn bộ tiến độ với hộp thoại xác nhận bắt buộc gõ đúng từ khóa `'XÓA'`.
6. **Tương thích Giao diện Di động (Mobile Responsiveness):**
   - Tối ưu hóa toàn bộ layout cho màn hình có chiều rộng 375px (chuẩn iPhone SE / iPhone 13 mobile) mà không phát sinh hiện tượng tràn màn hình ngang (horizontal scrollbar).

## 2. Chi tiết Kỹ thuật Triển khai trong `src/views/SettingsView.tsx`

### 2.1 Cấu trúc Quản lý Trạng thái AI & Bảo mật Khóa
```typescript
interface StoredAiConfig {
    authMode?: 'server' | 'client';
    apiKey?: string;
    baseUrl?: string;
    model?: string;
}

// Lưu trữ an toàn: Tuyệt đối KHÔNG lưu apiKey khi đang ở chế độ server
function saveAiConfig(
    mode: 'server' | 'client' = authMode,
    key: string = aiApiKey,
    baseUrl: string = aiBaseUrl,
    model: string = aiModel
) {
    if (typeof window === 'undefined') return;
    try {
        const payload: Record<string, string> = {
            authMode: mode,
            baseUrl: baseUrl.trim(),
            model: model.trim()
        };
        if (mode === 'client' && key.trim()) {
            payload.apiKey = key.trim();
        }
        window.localStorage.setItem('zhongxue.ai.config', JSON.stringify(payload));
    } catch {
        // ignore
    }
}
```

- Khi người dùng chuyển sang chế độ Khóa máy chủ (`authMode === 'server'`), trường `apiKey` lập tức bị loại bỏ khỏi `zhongxue.ai.config` trong `localStorage`.
- Nút "Xóa khóa" (`handleClearApiKey`) xóa trắng chuỗi key trong state, hoàn nguyên về `authMode: 'server'`, và dọn sạch `localStorage`.

### 2.2 Kiểm soát Ranh giới Bảo mật Upstream (A03 Security Compliance)
```typescript
const TRUSTED_AI_HOSTS = new Set([
    'agentrouter.org',
    'openrouter.ai',
    'api.openrouter.ai',
    'api.deepseek.com'
]);

function isTrustedBaseUrl(url: string): boolean {
    try {
        const parsed = new URL(url.trim());
        return TRUSTED_AI_HOSTS.has(parsed.hostname);
    } catch {
        return false;
    }
}
```
- Nếu `isTrustedBaseUrl(aiBaseUrl) === false`, giao diện hiển thị ngay cảnh báo an ninh màu hổ phách/chu sa, cảnh báo người dùng về việc máy chủ sẽ từ chối đính kèm khóa hệ thống cho endpoint này.

### 2.3 Thẩm định Sức khỏe Hệ thống (`/api/health`)
- Gửi yêu cầu với `Accept: application/json`.
- Kiểm tra `res.headers.get('content-type')?.includes('application/json')`.
- Đọc dữ liệu `HealthResponse` thực tế từ máy chủ:
  - `systemHealth.status`: 'ok' | 'degraded'
  - `systemHealth.dictionary.totalEntries`: số bản ghi thực tế (122.596 mục từ)
  - `systemHealth.dictionary.loaded`: trạng thái nạp tệp từ điển
  - `systemHealth.ai.configured`: trạng thái cấu hình khóa biến môi trường trên server
  - `systemHealth.version`: phiên bản hệ thống (2.0.0)

### 2.4 Thử nghiệm Độ trễ AI Ping (`/api/conversation` với `action: 'ping'`)
- Gửi payload `{ action: 'ping', model, baseUrl, apiKey }`. Nếu ở chế độ `server`, `apiKey` là `undefined`.
- Đo lường độ trễ từ lúc gửi đến lúc nhận phản hồi (`latencyMs`).
- Hiển thị thẻ kết quả xanh lá cây với nhà cung cấp, model và độ trễ mili-giây chính xác, hoặc thẻ màu đỏ với mã lỗi HTTP và thông điệp lỗi cụ thể từ máy chủ.

## 3. Bộ Kiểm thử E2E Playwright (`tests/e2e/ai-settings.spec.ts`)

Đã thiết lập bộ 5 ca kiểm thử tự động toàn diện:

1. **`server-key mode is selected by default with privacy isolation, no key sent in request`:**
   - Kiểm tra radio "Sử dụng khóa máy chủ" được chọn mặc định.
   - Xác nhận banner giải thích quyền riêng tư hiển thị đầy đủ.
   - Chặn bắt (intercept) request `/api/conversation` với `{ action: 'ping' }`:
     - Khẳng định `postData.apiKey` là `undefined` (không gửi khóa từ client).
   - Kiểm tra UI hiển thị thành công kèm nhãn độ trễ `128ms`.
2. **`custom key mode allows entering personal API key, persists to localStorage, and can be cleared`:**
   - Chọn chế độ Khóa cá nhân.
   - Nhập key `sk-personal-user-test-key-999` và lưu cấu hình.
   - Kiểm tra `localStorage` lưu trữ đúng key.
   - Kiểm tra lệnh ping chuyển tiếp key cá nhân trong body request.
   - Bấm nút "Xóa khóa", xác nhận ô nhập key biến mất, radio quay về Server-Key mode, và `localStorage` không còn chứa key.
3. **`custom/untrusted baseUrl displays A03 security boundary alert`:**
   - Nhập `baseUrl` lạ `https://attacker.evil.com/v1`.
   - Xác nhận cảnh báo an ninh Chính sách A03 xuất hiện ngay lập tức.
   - Chọn lại preset AgentRouter, xác nhận cảnh báo biến mất.
4. **`system health probe checks /api/health with application/json validation`:**
   - Bấm "Kiểm tra hệ thống".
   - Xác thực giao diện hiển thị đúng 122.596 mục từ, định dạng `application/json` hợp lệ, và mã HTTP 200 OK.
5. **`learning profile name and daily goal update with export/import roundtrip`:**
   - Cập nhật tên "Hoàng Long" và mục tiêu 50 XP.
   - Xuất dữ liệu ra file `zhongxue-tien-do.json`.
   - Xóa tiến độ với chuỗi xác nhận 'XÓA'.
   - Nhập lại file vừa xuất, xác nhận tên "Hoàng Long" và mục tiêu 50 XP được khôi phục 100%.

2. **Kiểm tra Tương thích Giao diện:**
   - `SettingsView.tsx` sử dụng selector ngữ nghĩa cao (Semantic Locators):
     - `page.getByLabel('Tên của bạn')`
     - `page.getByLabel('Mục tiêu mỗi ngày')`
     - `page.locator('input[type="radio"][value="server"]')`
     - `page.locator('input[type="radio"][value="client"]')`
     - `page.getByLabel('Khóa API AI cá nhân')`
     - `page.getByRole('button', { name: 'Xóa khóa' })`

     - `page.getByRole('button', { name: 'Kiểm tra hệ thống' })`
