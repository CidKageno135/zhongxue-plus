## 3. Các thay đổi kỹ thuật chi tiết (Green Phase)

### A. Biên dịch Server độc lập ra JavaScript thuần (`dist/server/index.js`)
- Cấu hình script `build:server` trong `package.json` sử dụng module runner của Vite SSR:
  ```json
  "build:server": "vite build --ssr server/index.ts --outDir dist/server --configLoader runner"
  ```
- Cập nhật script `build` trong `package.json` để biên dịch tuần tự cả client và server:
  ```json
  "build": "tsc -b && vite build --configLoader runner && npm run build:server"
  ```
- Kết quả artifact:
  - `dist/index.html` (SPA HTML)
  - `dist/assets/index-*.js`, `dist/assets/index-*.css` (Client bundles)
  - `dist/server/index.js` (Standalone Node.js Server bundle ~101 KB)

### B. Cập nhật `scripts.start` chạy Node thuần
- Thay thế `"start": "vite-node server/index.ts"` bằng:
  ```json
  "start": "node dist/server/index.js"
  ```
- Script `start` hoàn toàn không phụ thuộc vào `vite-node`, `vitest` hay `typescript`.
- Toàn bộ runtime của backend chỉ sử dụng Node.js built-ins (`node:http`, `node:fs`, `node:path`, `node:url`, `node:zlib`) và mã nguồn nội bộ đã được bundle, không phát sinh dependencies bên ngoài.

### C. Khắc phục ESM runtime compatibility trong `server/index.ts`
- Khi bundle dưới định dạng ESM (`"type": "module"`), Node.js không cung cấp biến toàn cục `__dirname` và `__filename`.
- B06 đã bổ sung khai báo toàn cục an toàn trong `server/index.ts`:
  ```ts
  const __filename = fileURLToPath(import.meta.url);
  const __dirname = path.dirname(__filename);

  if (typeof (globalThis as Record<string, unknown>).__dirname === 'undefined') {
    (globalThis as Record<string, unknown>).__dirname = __dirname;
  }
  if (typeof (globalThis as Record<string, unknown>).__filename === 'undefined') {
    (globalThis as Record<string, unknown>).__filename = __filename;
  }
  ```
- Giúp các module nội bộ như `server/dictionary.ts` nạp chính xác tệp nén từ điển `data/dictionary/CVDICT.u8.gz` (122.596 mục từ) trong môi trường bundle ESM mà không gặp `ReferenceError: __dirname is not defined`.

### D. Tăng cường an toàn và độ tin cậy trong `server/static.ts`
- Bổ sung mẫu kiểm tra `/server/*` vào `SENSITIVE_PATH_PATTERNS`:
  ```ts
  /(^|[/\\])server([/\\]|$)/i
  ```
  Ngăn chặn triệt để nguy cơ người dùng bên ngoài tải trực tiếp file mã nguồn hoặc file thực thi backend qua static server.
- Cải thiện hàm `resolveDistDirectory`:
  - Thêm ứng viên `path.resolve(__dirname, '..')` để tự động nhận diện thư mục `dist` gốc khi máy chủ chạy từ file bundle `dist/server/index.js`.
  - Ưu tiên chọn thư mục có chứa sẵn file `index.html`.

### E. Loại bỏ `--passWithNoTests` và thiết lập Coverage Thresholds
- Xóa cờ `--passWithNoTests` tại các script gate trong `package.json`:
  ```json

  "test:integration": "vitest run --configLoader runner tests/integration"
  ```

  ```ts
      lines: 80,

    }
  }
  ```
