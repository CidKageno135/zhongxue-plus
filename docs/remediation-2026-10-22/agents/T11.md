### 2.3. Chi tiết tái hiện F04: Cancellation & Upstream Abort (`tests/integration/ai-http-lifecycle.test.ts`)

1. **Client ngắt kết nối nhưng Upstream KHÔNG nhận được AbortSignal:**
   ```
   FAIL tests/integration/ai-http-lifecycle.test.ts > T11 Acceptance: AI HTTP Lifecycle & Cancellation (Invariant G3 / F04) > F04: Client Disconnect & Upstream Abort Signal > aborts upstream request when client disconnects during pending AI generation
   AssertionError: Upstream must receive AbortSignal when client disconnects during pending generation: expected false to be true
   - Expected: true
   + Received: false
   ```
   *Cơ chế lỗi:* Trong `server/ai.ts:548-554`:
   ```ts
   // Link client disconnect to abort signal
   const clientController = new AbortController();
   req.on('close', () => {
     if (!res.writableEnded) {
       clientController.abort(new Error('CLIENT_CLOSED'));
     }
   });
   ```
   Trong Node.js, `req` (`IncomingMessage`) phát ra sự kiện `'close'` ngay khi đọc xong luồng request body (sau sự kiện `'end'`). Khi handler đăng ký `req.on('close')` ở dòng 550, request stream đã kết thúc từ trước đó! Sự kiện này không bao giờ được kích hoạt khi client hủy TCP socket trong lúc chờ server trả lời. Do đó, `clientController.abort()` không bao giờ chạy, `fetch` ra upstream không bị ngắt, và tiến trình upstream tiếp tục chạy gây lãng phí tài nguyên và chi phí token.

2. **Ping Upstream HTTP 200 với Body rỗng (`""`) bị báo sai thành `ok: true`:**
   ```
   FAIL tests/integration/ai-http-lifecycle.test.ts > T11 Acceptance: AI HTTP Lifecycle & Cancellation (Invariant G3 / F04) > Ping Upstream Verification: Empty body or invalid schema must not be ready > rejects ping as ok=false when upstream returns HTTP 200 with an empty body
   AssertionError: Ping must NOT report ok=true when upstream returns HTTP 200 with empty body: expected true to be false
   - Expected: false
   + Received: true
   ```
   *Cơ chế lỗi:* `server/ai.ts:264-273`:
   ```ts
   if (pingRes.ok) {
     return {
       statusCode: 200,
       body: {
         ok: true,
         provider: providerLabel,
         model,
         ...
       }
     };
   }
   ```
   Chỉ kiểm tra `pingRes.ok` (HTTP 200..299) mà không đọc hay kiểm định body trả về.

3. **Ping Upstream HTTP 200 với Whitespace-only (`" \n\t "`) bị báo sai thành `ok: true`:**
   ```
   FAIL tests/integration/ai-http-lifecycle.test.ts > T11 Acceptance: AI HTTP Lifecycle & Cancellation (Invariant G3 / F04) > Ping Upstream Verification: Empty body or invalid schema must not be ready > rejects ping as ok=false when upstream returns HTTP 200 with whitespace-only body
   AssertionError: Ping must NOT report ok=true when upstream returns HTTP 200 with whitespace-only body: expected true to be false
   - Expected: false
   ```

4. **Ping Upstream HTTP 200 với Payload lỗi / sai Schema (`{"error": "..."}`) bị báo sai thành `ok: true`:**
