Điều này khiến `index.ts` có độ bao phủ 0% và test vẫn xanh ngay cả khi server thật bị hỏng.

   - **Loại bỏ in-memory mock duplex:** Thay thế `MockSocketDuplex` bằng việc thực thi chu trình HTTP thực thụ của Node.js (`http.Server` và `http.request`), đảm bảo các header, socket, mã trạng thái và stream body được kiểm thử toàn diện.
   - **Routing Isolation:** Mọi route `/api/*` không tồn tại phải trả về JSON 404 với envelope chuẩn `{"error": {"code": "NOT_FOUND", ...}}`, tuyệt đối không fallback về file HTML SPA (`index.html`).
   - **Path Traversal Protection:** Chặn đứng các hành vi duyệt thư mục (`/../.env`, `/%2e%2e/.env`, `package.json`, null byte) với HTTP 403 Forbidden.
   - **Sensitivity Enforcement:** Kiểm tra độ nhạy của test harness: khi server handler bị lỗi có chủ ý, test harness phải trả về lỗi thật, không được che giấu.

## 2. Thiết kế Bộ Acceptance Tests & Fixtures độc lập

T14 đã xây dựng 4 cấu phần kiểm thử độc lập:

### A. Fixture kiểm chứng đóng gói Production (`tests/fixtures/production/package-verifier.ts`)

### B. Cải tiến Harness Test Server (`tests/fixtures/api/test-server.ts`)
- Xóa bỏ hoàn toàn 150 dòng router mock fallback (`handleHealthRoute`, `handleDictionaryRoute`, `serveStatic` giả lập).
- Nối trực tiếp vào `createAppHandler` của `server/app.ts`.
- Sử dụng IPC local socket (`\\.\pipe\...` trên Windows) giúp Node.js thực thi đầy đủ giao thức HTTP Client/Server mà không gặp lỗi `EACCES` do sandbox hệ điều hành giới hạn loopback TCP connect.
- Đảm bảo mã hóa an toàn ký tự Unicode (như `學生`) trên query path khi gửi qua `http.request`, đồng thời bảo toàn chuỗi mã hóa gốc `%2e%2e` phục vụ kiểm thử bảo mật.
- Hỗ trợ tham số `customHandler` phục vụ kịch bản kiểm tra độ nhạy (sensitivity test).
- Tích hợp hàm đóng kết nối sạch `closeAllConnections()`.

### C. Bộ Integration Tests (`tests/integration/production-server.test.ts`)
Bao gồm 18 ca kiểm thử kiểm tra toàn diện API server thật:
1. `GET /api/health`: HTTP 200, schema `HealthResponse` chuẩn, đúng 122.596 mục từ CC-CEDICT, AI model `gpt-6.1-sol`.
2. Phương thức không hợp lệ trên `/api/health` trả về HTTP 405 Method Not Allowed.
3. `GET /api/dictionary?q=學生`: HTTP 200, kết quả tìm kiếm chính xác chữ Phồn thể/Giản thể và định nghĩa tiếng Việt.
4. `GET /api/dictionary?id=...`: Tra cứu theo ID hợp lệ trả về 200, ID không tồn tại trả về JSON 404.
5. `GET /api/conversation`: HTTP 200, trạng thái `ready`.
6. Routing Isolation: `/api/does-not-exist`, `/api/v2/nested/missing`, `/api/test.html` đều trả JSON 404, không bao giờ lộ HTML SPA.
7. Directory Traversal Protection: `/../.env`, `/%2e%2e/.env`, `/../package.json`, `/.env`, null-byte đều trả HTTP 403 Forbidden.
8. Static fallback: Non-API route hợp lệ (`/review`) phục vụ HTML SPA từ `dist/index.html`.
9. Clean Shutdown: Server đóng kết nối triệt để, không rò rỉ socket handle.
10. Sensitivity Check: Server handler cố ý ném lỗi thì client nhận đúng HTTP 500 `INTERNAL_ERROR`, chứng minh test harness không có shadow router che giấu lỗi.
