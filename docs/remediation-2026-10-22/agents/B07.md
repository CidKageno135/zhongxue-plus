## 2. Nguyên Nhân Gốc & Giải Pháp Kỹ Thuật Chi Tiết

### 2.1. Đồng bộ hóa nút phát âm & Quản lý vòng đời Speech Synthesis (`speech.ts` & `SpeakButton.tsx`)
- **Nguyên nhân gốc 1 (trong `src/services/speech.ts`):**
  - Khi trình duyệt hủy phát âm (do gọi `cancel()` khi có âm thanh mới hoặc người dùng bấm dừng), Chromium Web Speech API phát sự kiện `onerror` với `error === 'interrupted'` hoặc `error === 'canceled'`.
  - Mã nguồn cũ chỉ bỏ qua không hiển thị lỗi giao diện (`if (errType !== 'interrupted' && errType !== 'canceled') opts.onError(...)`) nhưng **quên không gọi `opts.onEnd?.()`**.
  - Do đó, component `SpeakButton` không nhận được tín hiệu kết thúc, dẫn đến trạng thái `isPlaying` bị kẹt ở `true`. Khi người dùng bấm nghe câu mới, nút của từ cũ vẫn hiển thị đang phát (2 nút cùng active).
- **Nguyên nhân gốc 2 (trong `src/components/SpeakButton.tsx`):**
  - Hook dọn dẹp cũ khai báo:
    ```tsx
    useEffect(() => {
        mountedRef.current = true;
        return () => {
            mountedRef.current = false;
            if (isPlaying) {
                stopSpeaking();
            }
        };
    }, [isPlaying]);
    ```
  - Khi `isPlaying` chuyển từ `true` sang `false`, React thực thi cleanup của render trước đó (vốn có `isPlaying = true`). Hàm cleanup này lại gọi `stopSpeaking()`, vô tình hủy luôn lượt phát âm của nút khác vừa mới bắt đầu!
- **Giải pháp xử lý:**
  - Trong `src/services/speech.ts`: Thiết lập hàm `markDone()` có cờ bảo vệ đơn kỳ vị `isDone`:
    ```ts
    let isDone = false;
    const markDone = () => {
        if (isDone) return;
        isDone = true;
        releaseUtterance(utterance);
        opts.onEnd?.();
    };

    utterance.onend = () => {
        markDone();
    };

    utterance.onerror = (e) => {
        const errType = (e as unknown as { error?: string })?.error;
        if (errType === 'interrupted' || errType === 'canceled') {
            markDone();
        } else {
            releaseUtterance(utterance);
            opts.onError?.('Chưa thể phát âm thanh trên thiết bị này. Hãy thử lại.');
        }
    };
    ```
  - Trong `src/components/SpeakButton.tsx`: Tách biệt việc lưu vết `isPlaying` qua ref `isPlayingRef`, và chỉ kích hoạt cleanup unmount thực sự khi component rời khỏi DOM (dependency array `[]`), loại bỏ hoàn toàn việc gọi nhầm `stopSpeaking()` giữa các lần re-render:
    ```tsx
    const isPlayingRef = useRef(isPlaying);

    useEffect(() => {
        isPlayingRef.current = isPlaying;
    }, [isPlaying]);

    useEffect(() => {
        mountedRef.current = true;
        return () => {
            mountedRef.current = false;
            if (isPlayingRef.current) {
                stopSpeaking();
            }
        };
    }, []);
    ```
